# ADR 0014: 근거 기록이 없던 값의 출처 분류

- 상태: 채택(2026-10-29, 표준성 점검 결정표 2절 '전 영역' 줄). 값은 바꾸지 않는다. ADR 0004·0007·0011의 "근거 기록 없음"을 이 표가 보충한다
- 날짜: 2026-10-29

## 맥락
표준성 점검(`docs/audit/standards-2026-10-29.md`)이 근거 없는 임의 값을 N-로 모았다. 결정은 값을 바꾸지 않고 출처를 측정·표준·제약 중 하나로 분류해 적는 것이다. 아래 분류는 코드·ADR·git 기록에서 확인한 것만 적었다. 아래 값 중 **측정한 것은 없다**(예외: 8MiB 삽입 0.09초와 ReDoS 입력 시간은 ADR 0003·0004가 이 PC 한 환경에서 쟀다).

## 왜 (따른 표준과 근거)
D89: 값은 측정·표준·제약 중 무엇에서 나왔는지와 측정하지 않았음을 적는다. 값을 바꾸면 측정 없이 다른 임의 값이 될 뿐이므로 바꾸지 않는다.

## 검토한 대안과 버리는 이유
- 지금 값을 측정해 바꾸기: 실제 저자 자료와 운영 환경이 없어 의미 있는 측정이 불가능하다. 버림.

## 결과
얻는 것: 사용자가 값의 근거를 물으면 "판단이며 측정하지 않았다"고 답할 수 있다. 감수하는 것: 값은 여전히 잠정이다.

## 되돌리는 조건
운영 측정이나 병원 정책이 나오면 해당 값을 설정으로 바꾸고 이 표의 행을 새 ADR이 대체한다.
